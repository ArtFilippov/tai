# Эксперименты с устойчивостью LLM

Система позволяет выполнять стратегии атак на языковые модели и оценивать предъявленные стратегиями текстовые результаты. Язык проекта различает результат атаки, успешность этого результата и ход выполнения эксперимента.

## Language

### Участники эксперимента

**User**:
Исполнитель стратегии, формирующий текстовый результат в ответ на базовый запрос. Один User может последовательно выполнять несколько независимых запусков.
_Avoid_: Attacker (для обозначения исполнителя стратегии)

**LLMChat**:
Собеседник на основе языковой модели, обладающий собственным диалогом. Стратегия выбирает действия в разговоре, а LLMChat владеет его историей.
_Avoid_: Generator

**Target**:
Роль собеседника, на которого направлена атака.
_Avoid_: Цель атаки (для обозначения собеседника)

**Attacker**:
Роль собеседника, помогающего стратегии строить и изменять атакующие обращения. Совпадение моделей в ролях Target и Attacker не объединяет их разговоры.
_Avoid_: User (для обозначения этой роли модели)

**Оценщик**:
Участник эксперимента, определяющий, достигнут ли успех в предъявленном результате атаки. Решение о продолжении или завершении запуска принадлежит User.

### Тексты и разговоры

**Message**:
Неизменяемый текст запроса, ответа или результата атаки с происхождением и историей преобразований. Сообщение не является разговором целиком.
_Avoid_: Диалог (как синоним Message)

**Базовый запрос**:
Текст прямого обращения к Target, которое стратегия пытается сделать результативным. Он не обязан быть первой отправленной репликой.
_Avoid_: Первая реплика (как название базового запроса)

**Базовый текст сообщения**:
Исходная версия текста в цепочке преобразований одного сообщения. Она не обязана совпадать с базовым запросом атаки или системными инструкциями разговора.

**Диалог**:
Упорядоченная последовательность сообщений с ролями, составляющая разговор одного LLMChat. Откат диалога меняет его активное продолжение, но не отменяет факт уже состоявшегося обмена.
_Avoid_: Message (как синоним диалога)

**Завершённый обмен**:
Обращение к LLMChat и полностью полученный ответ с их Message. Завершение обмена
само по себе не означает принятия ответа в результат атаки.

**Материал разговора**:
Сообщения активного диалога, которые стратегия может сохранить для продолжения.
В FITD realignment удерживает такой материал, не обязательно принимая его в результат.

**Контрольная точка разговора**:
Непрозрачный снимок завершённой истории, созданный LLMChat. Его валидностью и
восстановлением владеет LLMChat; идентификатор для наблюдения не заменяет его токен.

### Атаки и результаты

**Атака**:
Стратегия формирования текстового результата по базовому запросу с использованием взаимодействий с Target.

**Запуск атаки**:
Отдельное выполнение стратегии одним User с заданными участниками и базовым запросом. Повторный запуск начинает независимый эксперимент.
_Avoid_: User (для обозначения одного запуска)

**Остановка User**:
Запрос завершить запуск между вызовами: закрыть допуск новых действий стратегии
и дождаться уже допущенного модельного обращения или оценивания целиком.
Нормальные возвраты сохраняются; остановка не означает отмену обращения LLMChat
и не превращает завершённый ответ в предъявленный результат.

**Рабочее выполнение запуска**:
Работа стратегии, включая завершение обращений, фиксацию исхода и освобождение
участников. Возврат асинхронного старта означает допуск запуска, а не завершение
рабочего выполнения. Ожидание наблюдателем не является условием его завершения.
Внешнее сохранение результата выполняется после ожидания и не меняет исход User.

**Попытка FITD**:
Подготовленное garak обращение с идентификатором и состоянием продвижения по
лестнице. Выбранная следующая попытка может остаться неотправленной из-за лимита
раундов или завершения по оценке; это не отдельный запуск атаки.

**Серия запусков**:
Упорядоченное выполнение независимых запусков атаки по сохранённому манифесту с
общим профилем участников. Следующий запуск начинается после ожидания рабочего
выполнения предыдущего, освобождения его участников и внешнего сохранения итога
(либо фиксации ошибки сохранения). Индекс серии связывает исходные запросы с
предпринятыми запусками и их фактическими исходами; агрегированный отчёт использует
только сохранённые оценки финальных результатов. Прерванная серия содержит только
предпринятые попытки и явно отличается от полной.
Ошибки сохранения учитываются отдельно от фактического состояния User; ошибка
записи общих файлов серии завершает команду.
_Avoid_: Запуск атаки, журнал запуска (как синонимы серии)

**Результат атаки**:
Полный выходной текст, который User предъявляет от имени стратегии. Его содержание определяет сама стратегия: общий контракт не сводит результат к последнему ответу модели или всему диалогу.
_Avoid_: Журнал запуска, последний ответ Target (как обязательные синонимы результата)

**Оценка успеха**:
Суждение оценщика о конкретном предъявленном результате атаки. Удачный ответ в отброшенном материале не делает предъявленный результат успешным.

**Журнал запуска**:
Запись хода эксперимента, включающая обращения к моделям, ответы, преобразования, откаты, оценки и причины завершения. Отдельный объект владеет порядком, временем, диагностическими снимками, хранением и чтением записей; обёртки передают ему результаты наблюдаемых операций. Он сохраняет также отброшенный материал и сам по себе не является предъявленным результатом атаки. Каждый повторный запуск получает независимый журнал; его завершение следует за рабочим выполнением и освобождением участников.
_Avoid_: Результат атаки (как синоним журнала)

**Наблюдаемая операция выполнения**:
Действие рабочего пути с явными входами и содержательным результатом: решением,
изменением разговора или предъявленного результата, оценкой либо исходом работы.
Обёртка наблюдает эти значения и исключения; для записи журнала ей не требуется
читать приватное состояние или заново принимать решение стратегии.
