# BEAST для отдельного базового запроса

Закреплённый garak BEAST ищет суффикс на встроенных примерах и переносит его на другие запросы. Здесь каждый базовый запрос получает собственный поиск по предоставленному или подготовленному для него желаемому ответу. Это дороже, зато результат поиска относится к тому же запросу, который получает Target.

Сохраняем ширину луча 15, 15 продолжений на луч, 40 токенов и один trial по умолчанию. Следующий trial продолжает суффикс предыдущего, даже если общая длина превышает 40. Поиск минимизирует среднюю потерю желаемого ответа (в garak отрицательная perplexity сортируется в противоположном направлении). Первое расширение учитывается в длине; каждое следующее расширение использует собственный суффикс луча. Распределение для продолжения суффикса вычисляется внутри незавершённой реплики user; оценка ответа — после завершённой реплики user и начала ответа assistant. В обоих случаях текст запроса совпадает с итоговым обращением к Target, без отдельного системного промпта garak. Специальные токены не фильтруются. Seed и stop_early не предлагаются.

Только лучший по оценке поиска суффикс отправляется Target один раз после всех trials. Эвристика фраз отказа проверяет полный текст ответа вместо первого символа; она и оценка поиска остаются диагностикой. Оценщик проверяет только настоящий итоговый ответ Target относительно базового запроса. Отсутствие кандидата даёт no_result; сбой подготовки или вычисления остаётся ошибкой.

Поиск зависит от общего токенного контракта, а не от имени или ревизии Qwen. Контракт возвращает пакетные логиты на устройстве модели; токенизация и шаблон диалога принадлежат отдельному контракту, а вероятности и потери вычисляет отдельный слой. Transformers — одна из реализаций инференса; текущие команды по-прежнему собирают локальный Qwen.
