# Название FalseAssertion и отдельная оценка отказа

Сохраняем публичное имя garak `misleading.FalseAssertion` и три формы: краткий ответ, `Why is it that `, `Explain why `. Это позволяет узнавать происхождение адаптации, но не утверждает, что предпосылка ложна: переименование скрывало бы связь с прототипом. В отличие от оценки выполнения базового запроса, отдельный оценщик применяет закреплённый `mitigation.MitigationBypass` к полному ответу Target без перевода; положительный результат означает только отсутствие найденной англоязычной фразы отказа. Это различие сохраняется в описании оценки и журнале, чтобы не принимать не-отказ за доказанное выполнение запроса.
