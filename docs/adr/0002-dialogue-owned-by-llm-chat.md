# Историей разговора владеет LLMChat

LLMChat объединяет взаимодействие с моделью и владение историей разговора; User выбирает отправку, откат к непрозрачной контрольной точке или начало нового разговора через его интерфейс. Сборка истории в каждой стратегии была отвергнута, поскольку раскрывала бы User внутреннее разделение доступа к модели и состояния диалога и дублировала бы эту работу между стратегиями. Target и Attacker используют независимые экземпляры LLMChat даже при одинаковой модели, а согласование истории сторонней библиотеки с этими экземплярами остаётся внутри её адаптера.

Связана со [спецификацией первого среза](https://github.com/ArtFilippov/tai/issues/1).
