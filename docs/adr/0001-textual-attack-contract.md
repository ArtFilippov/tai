# Единый текстовый контракт атак

Все реализации User принимают базовый запрос и предъявляют результат одного общего типа Message: контракт атаки — текст в ответ на текст. Вместо отдельных типов результатов для каждой стратегии или обязательного представления результата последним ответом либо целым диалогом стратегия сама формирует выходной текст, который полностью передаётся оценщику. Журнал выполнения сохраняется отдельно: это позволяет исследовать отброшенные ветки, не превращая найденный в них удачный ответ в успех предъявленного результата; цена такого контракта — отсутствие общей структурированной схемы содержимого отчётов разных атак.

Связана со [спецификацией первого среза](https://github.com/ArtFilippov/tai/issues/1).
