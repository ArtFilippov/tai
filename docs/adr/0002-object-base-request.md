# Базовый запрос передаётся стратегии как объект

`Attack.run` получает базовый запрос с текстом и собственным происхождением: стратегия передаёт моделям только текст, а журналу сохраняет текст и метаданные начала запуска. Это расширяет границу атаки по сравнению со строкой, зато не требует собирать происхождение в каждом CLI или повторять полную таксономию пула в каждом журнале; свободный текст существующих команд представлен запросом без метаданных.
