# Настройки запуска принадлежат модели

Для события `start` журнала каждая модель предоставляет `Model.settings()` — JSON-совместимые идентификатор, ревизию и фактические настройки генерации. `ConfiguredJournal` назначает эти сведения ролям Target, Attacker и оценщика, не зная деталей GGUF. Это расширяет общий контракт `Model`, но позволяет контексту GGUF вернуть модель с достоверным статусом собственного или повторно используемого сервера; альтернативная сборка метаданных в CLI дублировала бы параметры запроса и знание о сервере.
