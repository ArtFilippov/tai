# Снимок сборки атаки формируют её участники

Вместо отдельной записи моделей `FITDAttack` сохраняет в событии начала вложенное описание Target, оценщика и стратегии: каждый участник явно описывает свои настройки через контракт, а модель предоставляет `Model.settings()`. Это заменяет сборку метаданных в `ConfiguredJournal` из ADR-0001: настройка одного участника больше не теряется при добавлении нового вида атаки, а сам журнал, не влияющий на поведение стратегии, не включён в снимок. Каждая запись получает версию схемы от реализации журнала через прозрачную обёртку; журнал серии отдельно ссылается на индекс.
