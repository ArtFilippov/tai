# Материалы приёмки #23

`evidence.tar.gz` содержит полные результаты двух зафиксированных запусков,
серверные логи, сырые TTY-кадры, интервалы обращений, исходники исполненной версии,
preflight и конкурентный smoke-test. В логах удалено только значение временного
локального server API key. `checksums.json` закрепляет байты архива и кратких
материалов. Сценарии записи и независимой проверки включены в архив.

`report.json` — результат полного прогона; `verified.json` — сверка identity,
финального Message, оценки, реконструкции, пересечения интервалов и очистки.
`console-frame.txt` / `console-frame.svg` — извлечённый кадр из настоящей TTY-записи
шириной 180 ячеек, а не реконструкция UI по journal.events.
Показатели и ограничения описаны в [отчёте](../2026-09-22-alert-vllm.md).
