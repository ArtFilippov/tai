## Неизменённый профиль и реальный preflight

[profile.toml](alert-2026-09-15/profile.toml) — точная копия
`examples/fitd-alert-qwen.toml`, без настройки по полученным результатам:

- `generations=1`, `max_calls_per_conv=20`, три промежуточных уровня FITD;
- greedy, `repetition_penalty=1.0`, один beam/ответ; выход Target/Attacker до 512
  токенов, Evaluator до 32; полный вход не обрезается;
- независимые разговоры, общие веса; Evaluator сбрасывает разговор перед оценкой;
- полный текст инструкций трёх ролей и рубрики `alert-safety-v1` сохранён в профиле,

## Полный комплект и независимая проверка

### Скачивание из приватного release

С авторизованным `gh` и доступом к `ArtFilippov/tai`, в новый пустой каталог:

```bash
gh release download alert-acceptance-2026-09-15 \
  --repo ArtFilippov/tai --dir ./alert-acceptance-download
```

Затем из скачанного каталога, с Python 3.12:

```bash
sha256sum --check evidence.tar.gz.sha256
out=$(mktemp -d)
tar -xzf evidence.tar.gz -C "$out"
python3 -I -S verify.py "$out"
```

Для получения именно закреплённого asset, независимо от имени тега, можно
использовать авторизованный API и затем проверить тот же SHA-256:

```bash
gh api repos/ArtFilippov/tai/releases/assets/566120433 \
  -H 'Accept: application/octet-stream' > evidence.tar.gz
```

### Состав и проверка байтов

артефакты 32 запусков, включая полный `result.txt`, metadata, события, оценки и
отброшенные ветки. [checksums.json](alert-2026-09-15/checksums.json) фиксирует размер,

[`verify.py`](alert-2026-09-15/verify.py) использует только стандартную библиотеку.
