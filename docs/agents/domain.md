# Domain docs

This is a single-context repository. Read the root `CONTEXT.md` before
exploring or describing the domain. Read relevant decisions in `docs/adr/`
when that directory exists; its absence needs no action.

Use terms from `CONTEXT.md` in issue titles, proposals, hypotheses, and
tests, including its explicit exclusions. If a needed term is missing,
reconsider the wording or note the gap for `/domain-modeling`.

Surface any conflict with an existing ADR explicitly.
