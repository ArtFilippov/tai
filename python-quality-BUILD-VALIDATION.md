# Проверка сборки

Дата: 21 сентября 2026 г. Среда: Linux, Python 3.13.5, uv 0.10.0.

**Выполнено:** 44 автономных теста, все успешно. Проверены чтение и применение
лимитов, идемпотентность применения и повторной установки, сохранение чужих
настроек, откат управляемых файлов при сбое, обработка неверных TOML, пропавшего
каталога правил, симлинков, исключений и тестовых профилей; парсинг Pylint/Pyright/
pydoclint/Tach; полнота запуска, приоритет кодов 0/1/2, отсутствие fail-fast,
неинициализированная архитектура, усечение только stdout, схема JSON. Проверены
реальные subprocess timeout/start failure и блокировка конкурентного запуска.

В тестах оркестрации вывод анализаторов и uv **подменяется тестовыми двойниками**.
Это не тестирование самих Pylint/Pyright/Tach/pydoclint. Журнал находится в
`validation/offline-tests.log` внутри распакованной поставки.

Проверены компиляция всех Python-файлов, оболочка self-extracting-архива, извлечение
в путь с пробелами, совпадение извлечённых файлов с payload и отклонение повреждённого
payload по SHA-256. Исходники установщика доступны через `--extract-only`.

**Не выполнено в среде сборки:** скачивание зависимостей и end-to-end установка
всех закреплённых анализаторов. У среды сборки отсутствовал сетевой доступ/DNS
из исполняемого контейнера, и этих пакетов не было в локальном кэше. Описания и
API сверены по официальной документации и исходникам; это не заменяет запуск.

При реальной установке скрипт `_audit.py` загружает зарегистрированные Pylint
extensions и архитектурный плагин, проверяет версии, разбирает конфиги и выполняет
smoke-тесты на намеренно ошибочных маленьких примерах. Ошибка не маскируется:
установка заканчивается кодом 2, управляемые файлы восстанавливаются, логи остаются.
Совместимость Alpha-плагина с каждым конкретным проектом не гарантируется.
