# Какие данные сохраняются при запуске FITDAttack на ALERT

Для одного запроса из ALERT сохраняются:

- Полный исходный текст запроса, его идентификатор, исходная категория, микро- и макрокатегория.
- Происхождение выборки и таксономии: ревизия источника, контрольные суммы и версия таксономии.
- Сведения, позволяющие связать запуск с его серией.
- Описание собранной атаки: используемая стратегия, Target, Attacker и оценщик, включая их вложенные зависимости.
- Настройки стратегии, в том числе предел обращений к Target в одном разговоре.
- Идентификаторы и ревизии моделей участников, параметры генерации и доступные сведения о среде их работы. При использовании внешнего сервера фиксируются только известные системе настройки.
- Обращения к Attacker, Target и оценщику: роль, переданный текст и полученный ответ. Для оценщика сохраняется также связь обращения с исходным запросом.
- Ответы Target, использованные стратегией, и решение о принятии либо отклонении каждого такого ответа.
- Заметки стратегии и материал разговора, относящиеся к попытке.
- Решения о продолжении или изменении атаки, подготовленный следующий запрос, сохранённая часть разговора и отброшенные реплики.
- Точный текст, выбранный атакой для оценки, отдельно от остальных ответов Target.
- Оценка этого текста и исходный запрос, с которым его сравнивали; при невозможности оценить — сведения об ошибке.
- Ошибки выполнения, причина завершения и итоговый исход, в том числе отсутствие предъявленного результата.
- Время сохранения записей; по началу и завершению штатного запуска можно определить его длительность.
- Идентификатор и версия схемы журнала, позволяющие проверить совместимость при чтении.

Для серии отдельно сохраняются запланированное и предпринятое число запусков,
категории и исход каждой попытки. По этим данным учитываются оценённые, успешные,
неуспешные и неоценённые запуски, ошибки, отсутствие результата и доля успешных
среди оценённых по микро- и макрокатегориям. Сводка не заменяет тексты и оценки,
сохранённые для отдельных запусков.

При сбое до начала атаки её описание может отсутствовать; связь с серией,
происхождение выбранного запроса и сведения об ошибке сохраняются.
